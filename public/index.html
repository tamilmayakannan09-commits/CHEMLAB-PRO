ℹ️ About ChemLab Pro
Project Overview

ChemLab Pro is a full-stack virtual chemistry laboratory application designed for college students and chemistry enthusiasts. It provides a safe, interactive environment to perform chemistry experiments, calculations, and learn chemical concepts.

Frontend: HTML5 + CSS3 + JavaScript (Vanilla)

Backend: Java Spring Boot (REST APIs, JWT Auth)

Simulations: Python (ChemPy, RDKit, SciPy, NumPy)

Database: PostgreSQL with Hibernate ORM

Deploy: Docker Containers on AWS EC2

Architecture & API
